# TeamFinder

Платформа для поиска команды на pet-проекты: пользователи публикуют идеи проектов,
присоединяются к чужим и добавляют проекты в избранное.

Реализован **вариант 1**: «Избранное» и фильтрация пользователей.

Стек: Python, Django 5.2, PostgreSQL 16, Docker Compose.

## Запуск

1. Окружение и зависимости:

   ```bash
   python3 -m venv venv
   source venv/bin/activate        # Windows: venv\Scripts\activate
   pip install -r requirements.txt
   ```

2. Настройки. Значения по умолчанию из `.env_example` подходят для локального запуска:

   ```bash
   cp .env_example .env
   ```

3. База данных (данные хранятся в volume `postgres_data`):

   ```bash
   docker compose up -d
   ```

4. Миграции и суперпользователь:

   ```bash
   python manage.py migrate
   python manage.py createsuperuser
   ```

5. Сервер:

   ```bash
   python manage.py runserver
   ```

Сайт: http://localhost:8000, админ-панель: http://localhost:8000/admin/

## Тесты

```bash
python manage.py test
```

## Структура

- `users` — модель пользователя, регистрация, вход, профиль, список участников.
- `projects` — проекты, участие, завершение, избранное.
- `templates_var1`, `static` — готовый фронтенд из заготовки.

## Отличия от рекомендаций

- `User.phone` не обязателен на уровне модели (`blank=True`): в форме регистрации
  телефона нет. Формат и уникальность проверяются в форме редактирования профиля,
  номер приводится к виду `+7XXXXXXXXXX`.
- Пользователи на странице участников отсортированы от новых к старым (`-id`),
  как указано в описании страницы.
- Фильтры пользователей не включают в результат самого текущего пользователя.
- Администратор управляет пользователями и проектами через админ-панель Django;
  блокировка аккаунта — снятие флага «Активен».
